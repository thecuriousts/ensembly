# Synthetic decision fixtures

Invented postings and invented labels for tests only. They are not operator
labels and they are not a measure of real accuracy. Companies and URLs use
the `example.test` / `* Fictional` / `* Sample` names already used in this
repo.

The frozen split (`e3-2026-11-13`) assigned these 60 rows before any
labelling of a real set: 36 train, 12 val, 12 held-out.
