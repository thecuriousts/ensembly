**Binding operator decision.** Apply Elon Musk’s 5-step algorithm + Odysseus core-nail to ensembly: one live operator kernel that **complements** Grok Bot / Grok Build / Cursor — not a competing “intelli OS.”

## 1. Question every requirement

| Former requirement | Verdict | Why deleted or parked |
|--------------------|---------|------------------------|
| Browser game as primary product surface | **Parked** → `prototype/public/game/` | Grok/Cursor are the capture harness; kernel emits gates/pulses, not canvas UX |
| Node `swarm.js` as co-equal control plane | **Parked** → `prototype/bin/` + `prototype/src/` | Duplicate wait-snapshot writer vs `peram-kernel` T1 SQLite; violated single-writer law |
| `peram-core` WASM in root workspace | **Parked** → `prototype/crates/peram-core` | World sim is optional client mirror, not ops SoT |
| Watch/dashboard as live glance product | **Parked** → `prototype/public/watch/` | Static export of legacy IR; kernel CLI + pulse-pack replace dogfood |
| npm as root prereq (Node ≥22) | **Removed from root** | Kernel is Rust-only; Node only for optional prototype |
| Game engagement pillars ($SPN, XP courtyard) in charter | **Demoted to prototype** | Fun remains valid experiment; not the 90-day operator bet |
| Eve/multiplayer/hub constellation as near-term build | **Parked in prototype docs** | Bridge trajectory documented; no second inbox |
| Drive / live cloud sync as dual writer | **Refused** | Pulse-pack file copy only; Grok Bot = canonical host |
| Greenfield kernel rewrite | **Refused** | Working `peram-kernel` simplified by **deletion**, not rewrite |

### Kept (core nail)

| Requirement | SoT |
|-------------|-----|
| HITL/HOOTL runtime (S+G+CP+P, MsgBus) | `crates/peram-kernel` |
| T1 SQLite one-writer, backup, ops-bundle | `peram-kernel` |
