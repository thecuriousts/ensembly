# Bundled fonts

Young Serif, Gaegu and DM Sans, Latin woff2 files, for the offline E5 chart page.
Licence: SIL Open Font License 1.1, in `OFL-YoungSerif.txt`, `OFL-Gaegu.txt` and `OFL-DMSans.txt`.

The page must not load fonts from Google Fonts or any other network host. `fonts.css` points only at these files.

| file | source |
|---|---|
| YoungSerif-Regular.woff2 | fontsource young-serif 5.2.6 latin 400 |
| Gaegu-Regular.woff2 | fontsource gaegu 5.2.7 latin 400 |
| Gaegu-Bold.woff2 | fontsource gaegu 5.2.7 latin 700 |
| DMSans-Regular.woff2 | fontsource dm-sans 5.2.8 latin 400 |
| DMSans-Medium.woff2 | fontsource dm-sans 5.2.8 latin 500 |
| DMSans-SemiBold.woff2 | fontsource dm-sans 5.2.8 latin 600 |
